# DiPlay Android 8.1 Port Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** DiPlay installs and runs on Android 8.0/8.1 (API 26/27) head units such as the MAXLINK GD230, with Android 9+ behaviour unchanged.

**Architecture:** Lower `minSdk` to 26, let Android lint (`NewApi`) enumerate every API 28+ call and guard each in the existing `Build.VERSION.SDK_INT` style, add one IPv4 fallback helper for wildcard socket binds, and hide Wi-Fi Direct below API 28. A new GitHub Actions workflow builds, tests, lints and smoke-tests the APK on an API 27 emulator.

**Tech Stack:** Kotlin, Android Gradle (Kotlin DSL + one Groovy module), ndk-build, JUnit 4 + Robolectric 4.17, GitHub Actions, `reactivecircus/android-emulator-runner`.

**Spec:** `docs/superpowers/specs/2026-10-07-android-8.1-port-design.md`

## Global Constraints

- `minSdk = 26` in `mobile`, `common`, `automotive`, `shared`; `APP_PLATFORM=android-26`. `compileSdk`/`targetSdk` unchanged (37).
- `abiFilters` stays `'arm64-v8a', 'armeabi-v7a', 'x86_64'`.
- Every change in upstream code carries a `// android-8.1:` comment.
- No accessory identity assets are added, extracted or referenced. `scripts/check_public_tree.py` must keep passing.
- The development Mac has ~200 MB free: **no local Gradle builds**. Verify by pushing to `fork` (`https://github.com/UrvaSuthar/DiPlay`, branch `android-8.1`) and reading the CI run.
- Working copy: `$TMPDIR/dp`. Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Head unit with IPv6 disabled in the kernel** — wildcard binds to `::` throw `SocketException: Address family not supported`; expect an IPv4 bind, not a crash (Task 3 test `fallsBackToIpv4WhenIpv6Unsupported`).
2. **User upgraded from a build that saved Wi-Fi Direct, now on API 27** — expect the stored `WIFI_P2P` mode to load as `MANUAL`, not start an unsupported backend (Task 4 test `wifiDirectFallsBackToCarHotspotBelowApi28`).
3. **API 28+ device after the port** — Wi-Fi Direct must still be offered and kept (Task 4 test `wifiDirectKeptOnApi28`).
4. **Both wildcard binds fail** — the original IPv4 error must surface and both sockets close (Task 3 test `rethrowsAndClosesWhenBothFamiliesFail`).
5. **Cold launch on API 27** — no `FATAL EXCEPTION` from `com.shihab.diplay` within 20 s of launch (Task 5 smoke job).

```kotlin
import org.junit.Assert.assertEquals
import org.junit.Assert.assertSame
import org.junit.Assert.assertTrue

class WildcardBindTest {
    private class FakeSocket : Closeable {
        var bound: InetAddress? = null
        var closed = false
        override fun close() { closed = true }
    }

    @Test
    fun bindsIpv6WildcardWhenAvailable() {
        val socket = WildcardBind.bind(::FakeSocket) { s, address -> s.bound = address }

    @Test
    fun fallsBackToIpv4WhenIpv6Unsupported() {

            }
        }.exceptionOrNull()
        assertSame(ipv4Error, thrown)
        assertTrue(created.all { it.closed })
```

```kotlin
package com.shilapi.xcertplay.airplay

import java.io.Closeable
import java.net.InetAddress
import java.net.SocketException

/** android-8.1: some API 26/27 head-unit kernels lack IPv6, so `::` binds throw (upstream #200). */
internal object WildcardBind {
    private val IPV6_ANY: InetAddress = InetAddress.getByName("::")
    private val IPV4_ANY: InetAddress = InetAddress.getByName("0.0.0.0")

    fun <T : Closeable> bind(create: () -> T, bind: (T, InetAddress) -> Unit): T {
        val socket = create()
        try {
            bind(socket, IPV6_ANY)
            return socket
        } catch (_: SocketException) {
            socket.close()
        }
        val fallback = create()
        try {
            bind(fallback, IPV4_ANY)
            return fallback
        } catch (e: SocketException) {
            fallback.close()
            throw e
        }
    }
}
```
